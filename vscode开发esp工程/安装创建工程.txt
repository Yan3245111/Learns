常用指令
idf.py build	编译项目（增量编译，只编译修改过的文件）
idf.py clean	清理编译产生的中间文件（保留配置）
idf.py fullclean	完全清理所有编译文件（包括配置）
idf.py reconfigure	重新生成 CMake 配置（修改了组件后执行）
idf.py build -j8	使用 8 个线程并行编译，速度更快
idf.py flash	编译并烧录到开发板
idf.py monitor	打开串口监视器查看日志


idf.py -p COM9 flash 进行烧录
idf.py -p COM9 monitor 进行查看板子运行打印的日志
idf.py -p COM9 flash monitor 烧录并回显打印

添加新的c和h模块文件
1. main文件夹同级目录 新建文件夹
在新建问价夹下新建c/h文件以及CMakeLists.txt
目录结构如下图
-main
    -main.c
    -CMakeLists.txt
-NewFloder
    -new.c
    -new.h
    -CMakeLists.txt
CMakeLists.txt

2. 更改新建CMakeLists.txt
idf_component_register(SRCS "new.c" 
                    INCLUDE_DIRS ".")

3. 更改根目录下的CMakeLists.txt 添加以下语句
cmake_minimum_required(VERSION 3.16)
include($ENV{IDF_PATH}/tools/cmake/project.cmake)

set(EXTRA_COMPONENT_DIRS "./NewFloder")  // 添加的这句

project(your_project_name)

4. 在main.c添加引用，首先要先定义new.h，然后idf.py build 不报错即可

5. 引用esp32内部文件 比如driver里的uart/gpio，报找不到文件错误
    解决办法：修改同目录下CMakeLists.txt  添加driver的语句
    idf_component_register(SRCS "sdk.c" "pack_utils.c" "model485.c"
                    INCLUDE_DIRS "." REQUIRES driver)
    idf.py fullclean
    idf.py set-target esp32se
    idf.py build 即可

6. 添加ws2811B led控制脚本
    idf.py add-dependency "espressif/led_strip>=3.0.0"

    在同级目录下CMakeLists.txt 添加 PRIV_REQUIRES led_strip （别的依赖文件也一样如此操作）
    然后执行
    idf.py fullclean
    idf.py reconfigure
    idf.py build
