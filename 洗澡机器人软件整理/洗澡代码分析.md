# 架构
1. 座椅(server) + 椅背(client-bath)
2. 通信方式：默认 ESP-NOW，支持WiFi 
    * 使用WiFi 要idf.py menuconfig → Triton server → WiFi SSID / 密码
3. 座椅：管充电、坞站、给椅背充电、收工序列。椅背回坞充电时，座椅给它送电
4. 椅背: 管搓背电机、沐浴脉冲、位置移动、被判死时收敛停机
    * 座椅发送指令给椅背，椅背移动到指定位置（坞站），触碰微动开关，开始充电
5. 供电系统：外部充电器（16.8V）-> 椅座 -> 椅座电池升压到16.8V -> 椅背回坞充电
6. 椅背心跳发送电量 -> 座椅，椅背回坞：低电被召回、正常工作结束。

# 代码流程
* 第一次烧录：芯片唤醒，判断唤醒条件
* 芯片进入深度睡眠，只留RTC计时 + 小一块ram，如果有信号进来就唤醒芯片，重新执行一次app_main()
    * esp_deep_sleep_start();  // 进入深度睡眠
    * esp_deep_sleep_wakeup_reason_get();  // 获取唤醒源
    * esp_sleep_enable_timer_wakeup(5 * 1000000);  // 5秒后唤醒
