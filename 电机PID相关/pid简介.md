# PID简介
* P是比例项，用于响应当前误差
* I是积分项，用于消除系统稳态误差
* D是微分项，用于预测误差变化趋势

# 作用解释
* P: 响应快慢、力度大小。
    * p越大，反应越快，力气大，太大就会震动、抖动、嗡嗡叫
    * p越小，反应越慢，跟不上目标，响应慢，达不到设定速度
* I: 消除静态误差
    * I会持续累计输出，把所有误差都加起来，得到一个总误差，然后根据总误差来调整输出，消除系统稳态误差
    * I越大：作用强，消除静差越快，太大容易震荡和过冲
    * I越小：作用弱，消除静差越慢，太小容易欠冲，比如目标400，总是在390达不到
* D: 抑制抖动，预判变化，刹车阻尼
    * 一般位置环才需要，速度环不需要
    * D越大可以抑制震荡，过大会噪声大，电机高频嗡嗡

# 参数调整
* D 直接给0，速度环不需要
* 安全准备：去掉负载，速度给小，
* P给大，I=0，D=0, 持续运行，看抖动，实际速度和目标差多少
* 速度远低于目标，说明p太小，需要调大，一直到嗡嗡响，小幅度震荡，回调20-30%，锁定P
* 开始设置I，I从0开始一点点往上加，小幅度叫，看速度能不能达到设置速度，如果过冲，说明I太大，需要调小
* 最后加上负载测试，看运行是否正常

# 三环：电流环、速度环、位置环
* 电流环：直接控制扭矩，响应最快，微秒级
* 速度环：控制转速，毫秒级
* 位置环：控制角度、位置、最慢
* 原则：电流环-速度环-位置环，先调电流环，再调速度环，最后调位置环，不是明面数字大小，而是实际内部增益大小
* 原则1：内环一定要大于外环，否则系统会震荡

* 电流环一般出厂会设置好，不建议调整
* 速度环D=0，然后调整PI，按照参数调整方法
* 位置环一般只调P，I=D=0，按照参数调整方法

# 现象参考
* 电机高频尖锐噪声，电流波动大，需要调电流环
* 电机运行抖动，掉转速，需要调速度环
* 电机位置过冲，来回摆动，位置环P过大
