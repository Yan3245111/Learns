# 硬件电路核心知识
    * 电路：由电源、负载、导线、控制元件组成的闭合电流通路，分为模拟电路（音频信号）和数字电路（01信号）
    * 电信号：直流信号（DC，交流信号（AC）
    * 核心参数：电压(U=I*R)，电流(I=U/R)，电阻(R=U/I)，功率(P=U*I=I*R*I)
    * 电路状态：闭合，断路，短路
# 硬件电路基础元件
    * 电阻（R）: 用于限制电流，分压。比如串联分流，5v1A电源，LED灯3.3V 20mA，需要分压1.7V，则电阻R=U/I=1.7/0.02=85Ω的电阻。
    * 电容：储存电荷，用于滤波、耦合、定时等。电压高了，存储电容，电压低了，放电出去，缓冲用，抹平电压波动。
    * 电感：储存磁场能量，用于滤波、扼流、谐振。
    * 二极管：单向导电，用于整流、检波、稳压。比如防反接
# 有源元件
    * 晶体管：电流放大或电子开关，模拟电路和数字电路核心。
    * 集成电路：IC，包含多个晶体管、电阻、电容、电感等元件，用于实现复杂的电路功能。
    * 电源元件：电池、充电器、电源适配器等，用于为电路提供电能。
# 电路基本规律：解决电流、电压、电阻的关系
    * 欧姆定律：U=IR，电压与电流成正比，与电阻成反比。
    * 基尔霍夫定律
        * 电流守恒：在任意节点，流入的电流总和等于流出的电流总和。
        * 电压守恒：在任一闭合回路，所有电压升的总和=所有电压降的总和。
    * 串联、并联电路规律：
        * 串联电路：电流相同，电压相加。
        * 并联电路：电压相同，电流相加。
# 常见基础电路
    * 电源电路：外部电源转换为电路电压 AC-DC, DC-DC等。
    * 放大电路：使用晶体管放大信号，增加信号强度。
    * 逻辑电路：处理01数字信号，实现逻辑运算（与、或、非取反、异或等）。
    * 震荡电路：产生周期性电信号，正弦波，方波等，用于时钟射频。
    * 滤波电路：用于去除信号中的噪声、干扰等，提高信号质量。核心元件：电容、电感、电阻。
# 电路设计原则
    * 元件选型匹配：
        * 电阻、电容、电感参数需满足最大电压、电流，避免过载损坏。
        * 有源元件IC（集成电路）：额定电流需要与电源匹配，避免过载损坏。
    * 布线与接地规范：
        * 电源线需粗化，减少线组，避免压降。高频信号需要短而直减少干扰。导线电阻R=导线电阻率*导线长度/导线 线截面积，长度不变的情况下，截面积越大，电阻越低。
        * 模拟地和数字地要分开连接，避免干扰。
    * 抗干扰设计
        * 开关信号：时钟、射频需原理电源、高压线路。
        * 敏感电路：传感器信号使用屏蔽线或并联电容滤波。
    * 安全性设计
        * 高压电路需增加保险丝，压敏电阻，防止短路、过载、过压等，损坏电路。
        * 电解电容、MOS管等有极性元件，需要标注正负极，避免接反烧毁。
    * 可维护性
        * 预留测试点，电源电压测试点，关键信号测试点
        * 元件布局合理，避免密集堆叠
    
# 电路基础知识
    * 电流：电荷的定向移动，单位A。
        * 短路：没有负载直接将电源的正负极连接，电流会升至最大，导致电源烧毁。
        * 串联电路：电流相同，电压相加。
        * 并联电路：电压相同，电流相加。
    * 电压：电荷在静电场中由于电势不同所产生的能量差，单位V。
    * 电阻：电荷通过导线时，会遇到阻抗，阻抗越大，电流越小。单位Ω。
    * 基尔霍夫定律
        * 电流守恒：在任意节点，流入的电流总和等于流出的电流总和。
        * 电压守恒：在任一闭合回路，所有电压升的总和=所有电压降的总和。

# 七大基础数据结构
    * 数组：连续存储的相同类型元素的集合，支持随机访问，插入和删除操作较慢。
        * 下标取值，复杂度O(1)，插入和删除操作复杂度O(n)。
        * 定长初始化要分配大小，容易溢出，动态分配内存(malloc)，用多少开多少，无空间浪费。
    * 链表：由节点组成，每个节点包含数据和指向下一个节点的指针，支持动态内存分配，插入和删除操作较快。
        * 没有下表，无法随机访问，查找数据需要遍历链表，复杂度O(n)。
        * 已知节点位置做插入、删除，只需修改指针指向，不用移动数据，复杂度O(1)。
        * 动态分配内存，用多少开多少，无空间浪费。
    * 栈：后进先出（LIFO）的数据结构，只允许在一端进行插入和删除操作。
        * 适用场景：函数调用、表达式求值、回溯算法等。
    * 队列：先进先出（FIFO）的数据结构，只允许在一端插入，在另一端删除。
        * 适用场景：任务调度、消息队列、缓冲区等。
    * 哈希表：通过哈希函数将键映射到数组索引，实现快速查找、插入和删除操作。
    * 树：由节点组成的层次结构，每个节点有零个或多个子节点，常用于表示层次关系，一对多。
    * 图：由顶点和边组成的数据结构，用于表示对象之间的关系，可以是有向图或无向图，多对多。
