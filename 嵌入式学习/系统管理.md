# 操作系统
* 三大角色：
    * 资源管理器：负责管理系统资源，如内存、处理器、磁盘等。
    * 抽象接口：提供给应用程序调用的接口，如文件系统、网络接口等。
    * 隔离保护：确保不同应用程序之间的资源隔离，防止互不干扰。
* 主流分类：
    * PC/服务器操作系统：如Windows、Linux。
    * 嵌入式：FreeRTOS、RT-Thread、嵌入式Linux。
* 四大核心
    * 进程管理
        * 组成：代码段、数据段、栈、堆、PCB（进程控制块）
        * 状态：就绪、运行、阻塞、创建、终止
        * 并发：单核CPU，快速切换多个进程，看起来同时运行
        * 并行：多喝CPU，多个进程真正同一时刻执行
        * 调度管理：时间片轮转，优先级调度等
        * 线程：进程中的一个执行单元，可以独立调度和执行。共享进程的堆、全局变量。
        * 进程/线程同步互斥（嵌入式高频使用）：多任务访问同一资源出现数据错乱，线程安全问题。
            * 互斥锁：同一时间只允许一个线程访问共享资源，可能有死锁，可以加超时。
                * 在访问共享资源前，先获取互斥锁。
                * 访问完成后，释放互斥锁。
                * 如果多个线程访问同一个资源，比如线程A被多次调取，需要自己加一把锁，如果线程A在访问自己资源时候也需要访问B资源，需要再加一把锁。
                * 两个线程互相访问且两个锁的情况，拿锁顺序要一致，否则会导致死锁。
            * 信号量：技术、限制最大访问数量，线程之间等待通知，但是不能保证操作本身安全，如果多个线程同时访问，会导致数据错乱，最好加互斥锁。
            * 条件变量（配合互斥锁）、消息队列：线程之间通信，协调资源访问。
        * 进程通信IPC
            * 管道：先进先出，单向通信，需要双向要开两个管道，父子进程间简单通信。
            * 信号：软件中断，用于通知进程事件发生，进程可以忽略，捕捉信号，异步通信，不知道信号什么时候进来。
            * 共享内存：同一块物理内存读写，所有进程都能看到，速度最快，需配合信号量和互斥锁使用。
            * 消息队列（message queue）：每个消息都有类型和数据，可以按类型读取。
            * socket
* 内存管理
    * 物理内存：内存条RAM
    * 虚拟内存：进程在内存中申请的内存，不是物理内存，而是通过页表映射到物理内存。
        * 地址隔离：进程之间互不干扰。
        * 内存置换：当物理内存不足时，操作系统会将不常用的内存页置换到磁盘上，释放物理内存。
* 文件管理
    * 把磁盘、Flash等块设备抽象成文件，比如普通文件、目录、串口、外设等。
