# 系统组成
    * Bootloader：负责上电后硬件初始化、加载内核
    * Kernel：负责管理硬件资源、提供系统调用接口
    * Application：用户空间应用程序，负责执行具体任务
    * RootFS：根文件系统，包含系统启动时加载的文件和目录
# 设备树
    * 定义了硬件的连接关系和功能
    * 用于描述硬件的配置信息
    * 用于在编译时生成内核模块
# 驱动开发模型
    * 硬件设备-总线-设备-驱动-内核
    * 总线：i2c、spi、uart等
    * 设备：sd卡、sd卡控制器等
    * 驱动：实现对设备的控制逻辑
# 平台驱动开发流程
    * 定义platform driver
    * 编写platform driver
    * 通过of_match_id匹配设备树节点
    * 实现probe/remove等接口
# Bootloader开发
    * U-Boot：一个通用的引导loader，用于在嵌入式系统中引导内核
    * 硬件初始化：初始化内存、外设、中断等
    * 驱动适配：根据开发板电路原理图，修改添加相应的驱动代码和配置
    * 内核编译：从SD卡中读取内核镜像和设备树，放入内存
# U-Boot开发
    * 准备源码sdk，下载交叉编译工具链
    * 配置U-Boot，创建板级目录，创建配置文件，创建板级头文件，更新Kconfig和MAINTAINERS
    * 配置核心，设备树配置，时钟晶振，调试串口，内存等参数，板级配置头文件
    * 编译U-Boot，生成可执行文件
